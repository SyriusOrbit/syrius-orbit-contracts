SyriusOrbit API overview.

SyriusOrbit is a spatial information and scheduling service platform for indoor Autonomous Mobile Robots (AMRs). Its API surface is organized into three contract suites:

  • SyriusOrbit Spatial API: OpenAPI contracts for OGC-aligned spatial data and geospatial services.
  • SyriusOrbit Fleet Management API: OpenAPI contracts for HTTP fleet resources and orchestration workflows.
  • SyriusOrbit Fleet Control API: AsyncAPI contracts for VDA 5050-aligned robot communication and fleet messaging.

SyriusOrbit Spatial API

OpenAPI contracts for spatial resources and OGC-style geospatial access.
